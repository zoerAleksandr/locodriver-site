5.Автоматическое продление Подписки (рекуррентные платежи)

5.1.Автопродление является дополнительной функцией и подключается только по желанию Пользователя. При оформлении Подписки Пользователь самостоятельно проставляет отметку в поле «Автопродление»; по умолчанию отметка не проставлена. Если отметка не проставлена, Подписка оплачивается однократно и по окончании оплаченного периода не продлевается.

5.2.Проставляя отметку в поле «Автопродление» и оплачивая первый период Подписки, Пользователь даёт согласие на регулярные (рекуррентные) списания стоимости Подписки с банковской карты без дополнительного подтверждения каждого списания, на обработку персональных данных и принимает условия настоящей Оферты. В тексте согласия, отображаемом рядом с отметкой, указываются выбранный тариф, сумма списания и его периодичность.

5.3.Автопродление доступно только при оплате банковской картой. Повторные списания производятся с той банковской карты, которой оплачен первый период, через Платёжный сервис «Robokassa». Реквизиты банковской карты Пользователь вводит на платёжной странице Платёжного сервиса; Исполнитель их не получает и не хранит. Для повторных списаний Исполнитель использует только номер первого (исходного) платежа.

5.4.Сумма первого платежа равна стоимости выбранного тарифа на момент оформления Подписки с учётом действующей в этот момент акции (скидки), если она применяется. Сумма каждого последующего автоматического списания равна стандартной стоимости тарифа без учёта акций и скидок, действовавшей на момент оформления Автопродления. Если при оформлении действует акция, в тексте согласия указываются обе суммы: первого платежа и последующих списаний. Периодичность списаний равна продолжительности оплаченного периода по выбранному тарифу: 31 (тридцать один) день — для тарифа «1 месяц», 93 (девяносто три) дня — для тарифа «3 месяца», 365 (триста шестьдесят пять) дней — для тарифа «1 год».

5.5.Списание производится за 1 (одни) сутки до окончания оплаченного периода. После успешного списания Подписка продлевается на следующий период, который отсчитывается от даты окончания текущего оплаченного периода. Дата и сумма ближайшего списания отображаются в Приложении в разделе «Профиль → Подписка».

5.6.Если при подключённом Автопродлении Пользователь оплачивает Подписку самостоятельно, дата следующего автоматического списания переносится на окончание нового оплаченного периода. Повторного списания за один и тот же период не производится.

5.7.Сумма автоматических списаний, указанная в согласии Пользователя, не изменяется в течение всего срока действия Автопродления: ни при изменении тарифов Исполнителем (п. 4.2 Оферты), ни при акциях и скидках, действующих на момент очередного списания. Акция, действовавшая при оформлении, распространяется только на первый платёж. Списание по иной стоимости возможно только после того, как Пользователь даст новое согласие при очередной оплате Подписки.

5.8.Если списание не состоялось (в том числе из-за недостаточности денежных средств, отказа банка-эмитента или недействительности карты), Исполнитель повторяет попытку через 1 (одни) сутки.
