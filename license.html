Пользовательское соглашение для мобильного приложения «Машинист»

Редакция от 16 июля 2026 г.

Настоящее Пользовательское соглашение для мобильного приложения «Машинист» (далее по тексту — Соглашение) определяет условия предоставления Ящуком Александром Александровичем (далее по тексту — Лицензиар) права пользования конечным пользователем (далее по тексту — Лицензиат) приложением «Машинист» (далее по тексту — Приложение) для мобильных устройств.

Приложение служит для учёта и хранения данных о времени работы, локомотивах, поездах и прочей информации, касаемой работы машиниста и помощника локомотива, а также автоматизирует расчёт нормы отдыха между поездками, количество расходуемой энергии.

Соглашение содержит специальные нормы, которые регулируют отношения между Лицензиатом и Лицензиаром по использованию Приложения.

Приложение предназначено для работы на устройстве с операционной системой Android.
